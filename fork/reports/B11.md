### WO-B11-009 SUPP-18 verdict (run 62)

- `checks/supp-serp-originality.ts` (`llm.supp-serp-originality`, registered in `checks/index.ts`): reads `ctx.serpOriginality`; option off → no status; REVIEW → N/A `REVIEW mode: search-results data not used, EP-7`; no selectable page → N/A; collection BLOCKED records stay BLOCKED (never a finding).
- Verdict: one call per page through `SerpCollection.judge` (`SerpJudge`, contracts 1.7.0 additive: `serpVerdictSchema`, `SerpJudge`, `judge` on the `ran` collection). Input: URL, title, H1, own profile facts, main text (8 000 chars from the H1) and the competitor profile facts (type, topic, stats, prices, names, awards, headings, key facts). Quotes verified verbatim (whitespace-normalized) on the page text; unverified ones dropped; a "yes" left with no verified quote → `unsure`. Confidence < 0.7 → second call; different answer → `unsure`; same answer → higher confidence kept. Finding only for a confident (≥ 0.7) "no": title / fix / S3 verbatim from §3.3, effort M, `source: llm`.
- Evidence: one `artifact` per page (JSON body = the `SerpOriginality` record with verdict or BLOCKED reason) + one `textQuote` per verified element. PASS cites the artifacts.
