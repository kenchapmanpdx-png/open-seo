## Decisions (For Ken)

- WO-001 / 002 / 004 severities: ADR-038. Revert phrases: "missing canonical stays S1", "named-group gap stays S1", "x-default required".
- WO-005 run year: checks get no run date (adding one is a contracts change, not allowed here). The year is the page's HTTP `Date` header (stored with the snapshot), else the newest `Date` header of the crawl, else the current UTC year. A stored crawl judges the same on every rerun. Revert: "any year in headings".
- WO-003: also fixed `bot-parity.ts` and `hidden-pages.ts`, which asked the same question with the path only (the source scan found them). Two fixed-path calls (robots sample paths, policy-map home) carry a `// robots path:` note.
- WO-006: one retry per token, and only until one retry is still 429 (bounds the map at one Retry-After wait). Revert: "429 counts as a block".
- BadGEO: no page covers a missing canonical on an indexable page, hreflang, variants or P4-06 (README: unit tests only), so no expectation moved. `/robots.txt` expects `P3-15`, `P9-05` without a severity: unchanged.
- Handbook conflicts (§10 self-canonical; §18 named groups): ADR-038 § Handbook conflicts.
