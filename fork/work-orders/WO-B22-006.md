## Purpose

[Ken 2026-11-19] GSC + GA4 is a must-have. The fix list gets a real-world signal: findings on pages with impressions / clicks / sessions sort first, so the fix list answers "what do I fix first on pages that earn traffic".

## Constraints (decided now)

- Ordering and a "pages with traffic" label only. The score, severities and caps never read ranking, traffic or backlink data (EP-7; handbook rule for REVIEW mode, `contracts/scoring.ts`).
- Uses the upstream GSC / GA4 features already in the app (`src/server/features/gsc`, `ga4`) through their services; no second OAuth path, no new secrets.
- Properties not connected → fix list unchanged (no empty "traffic" column).
- Start with a short design note (ADR) before code: data shape per URL, date window, privacy (aggregate counts only stored in the report, no query text), failure behaviour (`unavailable`, never a guess).
