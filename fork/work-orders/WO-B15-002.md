# WO-B15-002: Resource status — img / CSS / JS (§9 #2)

- Batch: B15 · Class: HEAVY · Size: L
- Contracts: 1.9.0 (additive, ADR-031 with #3, #4)
- Depends: WO-B15-000 (shared contract bump)
- Spec: `fork/ACCURACY.md` AT2 · §9 #2 (T1, T20)

## Spec

- Every `<img>`, stylesheet and script URL on read pages, deduped: HEAD → GET fallback (405 / 501 / no length) → browser-UA retest on 403.
- Broken = 404 / 410 / DNS fail / 5xx after retest. Bot-only 403 = info, never broken.
- One finding per resource URL with page count and sample pages (logo ×64 on salonvata).
- Budget per run in ADR-031; over budget → cap note.
- Evidence: URL, method, status per attempt, UA used.

## BadGEO

- Page with a broken image used on 2 pages (expect one finding, count 2); page with a bot-403 / browser-200 resource (negative).
