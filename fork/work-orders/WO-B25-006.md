## Class

`checks/platform.ts` knows builders without a generator meta only by their script / media hosts (Showit, GoDaddy, Duda, Weebly, Jimdo …). BentoBox, a hosted restaurant builder, is missing.

## Steps

1. **Red test** (public entry point: the platform check, `checks/platform.test.ts`): a home snapshot whose scripts load from `theme-assets.getbento.com` and `app-assets.getbento.com` → today "Platform not identified". Save to `fork/runs/b25/wo006-red.txt`.
2. **Class fix**: add `{ test: /(^|\.)getbento\.com/i, platform: "BentoBox", builder: true }` to the host list beside Showit. Check whether any builder-limited item needs BentoBox wording; if none, record "BentoBox uses the generic builder wording".

## Guards

- Existing Showit / Weebly / Duda host tests still pass.
- A site with a platform header (e.g. `x-wix-request-id`) that also embeds one `images.getbento.com` image keeps its header platform (header signal wins, as today).
