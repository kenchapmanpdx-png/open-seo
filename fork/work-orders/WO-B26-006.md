- Steps:

If the probe cannot tell a DNS "no such name" from a timeout without a new contract field → treat every no-answer as "not confirmed" and ESCALATE the DNS split. For Ken: say "no answer counts as dead" to revert.
  3. Apply the same rule to un-crawled internal link targets and page resources only if they share `deadReason`; otherwise leave them and note it.
- Guards: 404 / 410 still dead (true case). A domain that does not resolve is still dead when the probe can prove it.
- Do not: add more retries inside the 2 s policy (ADR-035: never a burst).
