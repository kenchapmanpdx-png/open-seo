## Spec

1. `fork/MAINTENANCE.md` M6 gains "Convergence" (below). `fork/reports/convergence.md` is written by `fork/scripts/field-test.ts --convergence` from the ledgers and verdict tables (never by hand): one row per round.
2. Definitions:
   - **Round**: ≥ 3 field tests with matched scope (size gate) run on one release tag. Backfill by tag from `fork/FIELD-TESTS.md`: R0 B18 / B19 sites (spoiledspaandsalon, nwpersonaltraining, wsparkdental, valentinecoffeeco, aircorheatingcooling), R1 sites 6–8 (bluebonnetroofs, theogdenver, samanthaco; pre-B20 fixes), R2 `handbook-v3.9.0` (love4pawsrescue, mobilepetgroomingaz, aweandorderorganizing), R3 = WO-B22-004. R0 / R1 rows marked "scopes unmatched" where the ledger shows it.
   - **Ranking-relevant miss**: a Semrush-only row whose verdict is `fixed` or that produced a WO, mapped to a registry item whose effect is not `hygiene` (WO-B22-001); before that WO ships, every such row counts.
   - **Error**: any `check error` or collector error in a valid run (`golden-score` exit 1 rule).
   - **Unexplained finding**: an app-only finding with no live-checked verdict in the ledger.
3. **Done** = two consecutive rounds, each with 0 ranking-relevant misses, 0 errors, 0 unexplained findings, and at least one round containing a matched-scope site of ≥ 100 sitemap URLs. A round with a miss resets the count; the fix goes through the prevention rule and the same sites are rerun in the next round.
4. Report the current state in every batch report: rounds table, misses by class, rounds left.

## Guard

- `field-test.convergence.test.ts`: fixture ledgers → exact round table; a round with one `fixed` verdict on a non-hygiene item resets the streak; two clean rounds flip "done"; an unmatched-scope round never counts toward "done".
