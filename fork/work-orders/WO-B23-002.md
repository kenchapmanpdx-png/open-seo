# WO-B23-002: P3-15 / P9-05 — named-group gaps judged by crawl outcome; S3 "intended?"

- Batch: B23 · Class: HEAVY · Size: M
- Contracts: none
- Depends: —
- Registry items: P3-15, P9-05

## Red case (SUPPORTED: source read at `f1ce14b1`; no run)

`checks/robots-groups.ts` `namedGroupGaps`: `missing = [...star].filter((p) => !merged.has(p))` compares rule strings. `proof` is built with `decide()` and never filters. Reported as gaps although the named bot is not let into anything:

- `*`: `Disallow: /private/` · named: `Disallow: /private` (broader).
- named: `Disallow: /` (blocks everything).
- named carries the same paths plus a longer `Allow` / `Disallow` that decides the sample path.

Severity: any search or AI bot → S1, cap 39. Google (create-robots-txt, read 2026-11-24): a crawler follows only its most specific group; per-crawler groups are documented practice. The app cannot know intent.

## Class

A text difference is reported as a crawl-policy error, and a policy difference as an indexing failure.

## Decision (default)

- A pattern is a gap only when, on its sample path, the named bot is **allowed** and an unlisted bot is **blocked** (`decide()` for both; already computed for `proof`).
- A real gap = that bot may crawl more than other bots: not an indexing or ranking loss by itself → **S3**, title ends "— intended?" (pattern of SUPP-13). `severityReason` "the named group lets this crawler into paths other crawlers are kept out of; deliberate per-crawler rules are valid".
- Fix text: per bot, sample URL and outcome; "copy the `*` Disallow lines into the group" only as the step when the difference is not intended; keep "or drop a named group that only restates `Allow: /`".
- "For Ken: say 'named-group gap stays S1' to revert." Listed in ADR-038.

4. `engine/s1-scope.ts`: remove P3-15 / P9-05 from `ACCESS_S1` only if no check still emits S1 for them (`s1-scope.test.ts` guard decides); otherwise leave.

6. PASS text when no gap: "no named group lets a crawler into paths `*` blocks".
