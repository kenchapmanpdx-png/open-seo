## Spec

- Bind = pick from `getSites` (no free text); `verified` copied from the site list.
- Daily per bound site: crawl stats + rank-and-traffic → `bing_daily_traffic`; query/page stats → `bing_query_week`/`bing_page_week` (week_start = Monday UTC); crawl issues → `bing_crawl_issue` (keep `first_seen`, bump `last_seen`); upsert by natural key; `bing_sync_state` success/error. Throttled → stop this site for today.
- Key from `CredentialRepository.getBingKey` (WO-B6-001); none → skip silently, state `last_error = 'no key'`.

## Conventions

- Tables already exist (B5 R4a): import them from `@/db/integrations-tables` (provider-aware); never from a dialect file. Repository → service → server fn (AGENTS.md).
