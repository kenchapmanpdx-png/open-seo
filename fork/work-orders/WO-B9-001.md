## Spec

- `HANDBOOK_DEPTH` = `full` (default) | `quick`; CLI `--depth` wins. `quick` = today's behavior (CI, BadGEO default). Report header states depth; grades compare only within one depth (EP-7).
- `HANDBOOK_MAX_PAGES` default 1000 (app + CLI); CLI `--max-pages` overrides.
- Infinite-space guard: after 300 pages, ≤ 100 pages per template; query-string URLs deduped to their canonical; `?page=`, `/page/N/` and date paths (`/YYYY/`, `/YYYY/MM/`) capped at 20 each.
- Over cap: stratified fill — every template's rank-1 first, then round-robin per template until cap.
- Coverage `{discovered, read, capped}`; line "read N of M discovered"; grade flagged `partial coverage` when read/discovered < 0.9 (flag only; score unchanged).
- Status mapping: no new item status; RV-02 stays PASS (report sections complete).
