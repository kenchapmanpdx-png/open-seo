## Spec

- P3-01 rule text (verbatim, §41): "[T1+] Apex↔www and HTTP→HTTPS: one-hop 301/308, never 302/307 (§10)"
  - class CRAWL (+HEADERS) · automatable full · severity S1 (scale)
- P3-02 rule text (verbatim, §41): "[T1+] One trailing-slash policy on every route incl. nested; other form 301/308 (§2)"
  - class CRAWL · automatable full · severity S3 (default)
- P3-03 rule text (verbatim, §41): "[T1+] Nav/logo → `/`, not `/index.html`; query variants canonicalize to clean URL (§2)"
  - class CRAWL · automatable full · severity S3 (default)
- Logic:
  - Input: `variants.probes` (http-apex, http-www, https-apex, https-www, index-html, trailing-slash / no-trailing-slash, uppercase-path).
  - P3-01: every non-canonical host/protocol probe must reach the canonical origin in exactly one hop with 301 or 308. OPEN on: 302/307 anywhere in `redirectChain`; >1 hop; final URL ≠ canonical origin; non-canonical variant answering 200 (duplicate host). Probe that failed to fetch (DNS/no TLS on www) → note only, not a finding.
  - P3-02: the toggled-slash probe must 301/308 to the crawled form in one hop. 200 on both forms = duplicate (OPEN). 404 on the other form = PASS (one policy). Check 2 inner URLs if available (nested routes): add a second toggled probe only if the collector already has it — do not change the collector contract.
  - P3-03: `index-html` probe must 301/308 to `/` or 404; 200 = OPEN. Any crawled page linking to `/index.html` (pages.links) = OPEN (cite source URLs). Query-variant canonicalization: for home, `?utm_source=x` canonical — not probed by the collector; record PASS note 'query variants not probed' and leave to WO-003.
  - Canonical origin = home snapshot canonical origin, else `ctx.origin`.
- Status mapping: PASS when every probe obeys the rule · OPEN per violation · NA when the variants collector produced no probes for that item · BLOCKED via runner when `variants` unavailable
- Severity: registry `severityDefault` per item; any other severity needs `severityReason` (runner rejects the finding otherwise).
