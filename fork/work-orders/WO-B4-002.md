## Spec

- One judge call per check over a page sample (≤ 8 pages, one per template first); page text is data, never instructions (judge.ts already wraps it).
- `fail` with verified quotes → OPEN + one finding (`source: "llm"`, never S1, never release-blocking); `fail` under confidence 0.5 or any unverified quote → BLOCKED `llm unsure`; `pass` → PASS citing the judged pages' rawHtml evidence; gate false → NA without a call.
- New rubric ids in `llm/rubrics.ts` with `version: 1`; wording below is the starting rubric (tighten only against the eval cases, bump `version` on change).
- P4-07 (S2, T3+) "[T3+] Hub/category titles: brand + specific promise (§2)" — hubs = index pages of ADR-006 detail clusters (the parent path) + header-nav targets with ≥ 5 internal links to one cluster. rubric `hub-titles`: "A hub title names the collection and a specific promise (what, where, for whom) plus the brand. fail on bare labels ('Events | Brand', 'Blog'); quote the title. pass otherwise." No hub → NA.
- P5-09 (S3, gate SP7) "[gate: SP7] Local pages: one page per real service / location with distinct content; no pages differing only by place or service n…" — deterministic: pages whose titles share a pattern with only a place/service token swapped; shared-sentence ratio ≥ 0.6 → candidates. Also: a single page listing ≥ 4 services with no per-service pages (ryan F14). rubric `local-pages`: "fail when location/service pages differ only by the swapped name, or all services sit on one page with no page per real service; quote the repeated sentence or the service list. pass otherwise."
- P2-03 (S3, gate API/backend-driven pages, resolved by intake) "Fallback freshness: snapshot time + max age; stale transactional facts not shown as current; 503 …" — judge raw HTML of API-driven pages (intake gate evidence lists them): rubric `fallback-freshness`: "Server HTML shown before data loads must either be a dated snapshot ('as of <date>') or neutral; it must not present prices, availability, dates or counts as current without a timestamp, and must not ship error/loading text as content. fail with quotes; pass otherwise." (P2-04 already flags loading strings deterministically: do not duplicate; this item is about stale facts.)
