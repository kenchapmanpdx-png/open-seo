## Spec

- One judge call per check over a page sample (≤ 8 pages, one per template first); page text is data, never instructions (judge.ts already wraps it).
- `fail` with verified quotes → OPEN + one finding (`source: "llm"`, never S1, never release-blocking); `fail` under confidence 0.5 or any unverified quote → BLOCKED `llm unsure`; `pass` → PASS citing the judged pages' rawHtml evidence; gate false → NA without a call.
- New rubric ids in `llm/rubrics.ts` with `version: 1`; wording below is the starting rubric (tighten only against the eval cases, bump `version` on change).
- P5-06 (S3) "[T1+] Page-type matrix applied: no article furniture (byline, takeaways, citation lists, visible last-updated) on home, service, product…" — rubric `page-type-matrix`: "Handbook §7 page-type matrix: home, service, product, location and contact pages carry no article furniture (author byline, 'key takeaways', citation lists, visible 'last updated' stamps); articles and guides may. fail when a non-article page carries article furniture; quote it. pass otherwise." Sample: one page per non-article template + home.
- P5-11 (S3) "[T1+] Awards, press, certifications as HTML text with awarding body + year + source link (§6)" — deterministic pre-pass: `<img>` whose alt/src/filename contains award|badge|certified|winner|best-of|press|featured and no nearby text naming a body + year → candidate. Judge gets candidates + the surrounding text. rubric `awards-as-text`: "fail when an award, press mention or certification is shown only as an image, or as text without the awarding body, the year, or a link to the source; quote the text or the image alt/src. pass when every one is complete text." No candidates and no award words in text → NA ('no awards found').
- P5-15 (S3, gate T3+) "[T3+] Detail pages: unique primary-source facts + key-facts block (§6, §7)" — per detail template (ADR-006 clusters, ≥ 3 URLs) sample 3 pages; rubric `detail-key-facts`: "Each detail page has a key-facts block (list/table of the item's own facts: date, place, price, distance, specs…) and facts unique to that item, not template copy with the name swapped. fail when a page lacks the block or its body is mostly shared boilerplate; quote the boilerplate or name the page. pass otherwise." Include word count + shared-sentence ratio (sentences appearing on ≥ 2 sampled pages ÷ all) in `facts` so the judge has numbers.
