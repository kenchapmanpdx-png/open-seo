## Class

`engine/minhash.ts` `mainTextFacts` counts blocks from raw HTML main text, including copies that the page hides: by inline `display:none`, the `hidden` attribute, `aria-hidden="true"`, or a page `<style>` rule that hides a single-class selector in one layout (Showit `.d .x` / `.m .x`, or the same rule inside an `@media` block). Builders that print a desktop and a mobile copy produce SUPP-03 on every such block.

## Steps

1. **Red tests** (public entry point: `mainTextFacts` → the duplicates check, `engine/minhash.test.ts` + `checks/duplicates.test.ts`): (a) the bluebonnetroofs.com pattern — two 20-word copies in `.sie-a` and `.sie-b`, page `<style>` `.m .sie-a{display:none} .d .sie-b{display:none}` → today `duplicateBlocks` count 2 and SUPP-03; (b) the valentinecoffeeco.com pattern — second copy inside `aria-hidden="true"` → today SUPP-03. Save to `fork/runs/b25/wo007-red.txt`.
2. **Class fix** at `mainTextBlocks` (the one place blocks are cut): tag each block with the layouts in which it is hidden — all layouts for inline `display:none`, `hidden`, `aria-hidden="true"`; one layout for a page `<style>` rule of the form `.<scope> .<class>{display:none}` or `@media (…) { .<class>{display:none} }`. A block counts as repeated only when ≥ 2 copies are visible in the same layout. Raw HTML and page `<style>` blocks only: no external stylesheets, no rendering. `mainWords` and the minhash keep today's text so near-duplicate and thin-page results do not move. For Ken: say "count hidden copies" to revert.
3. Re-derive SUPP-03 for every run in the table from stored raw HTML; record per site. Expected: bluebonnetroofs.com closes; valentinecoffeeco.com keeps 1 block; all others unchanged.
