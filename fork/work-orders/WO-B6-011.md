## Spec

- Per ADR-013 §1 steps 1–6. Signature: HMAC-SHA1 hex of raw body with `DRAIN_SECRET`, `timingSafeEqual`; mismatch → 403 before parsing. Body > 4 MB → 413.
- Site resolution: `select id from ai_traffic_site where vercel_project_id = $1`, then host filter via `ai_traffic_site_host` (no rows = all hosts). Unknown project → discard row with `site_id` NULL.
- Events: `insert … on conflict do nothing` (no target). Discards: `insert … on conflict (vercel_project_id, hour) do update set count = ai_traffic_discard.count + excluded.count`; hour = `YYYY-MM-DDTHH` UTC of the entry.
- Event `id` = `crypto.randomUUID()`; `event_id` = Vercel request id.
- Receiver never classifies (ADR-013).
