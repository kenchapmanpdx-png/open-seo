# WO-B15-004: Outbound link classes (§9 #4)

- Batch: B15 · Class: HEAVY · Size: M
- Depends: WO-B15-002 (shared probe path)
- Spec: `fork/ACCURACY.md` AT4 · §9 #4 (T15)

## Spec

- Dead outbound (DNS fail, 404, 410) = finding. Platform bot blocks (e.g. 403 / 429 / 999 from social platforms) and redirects = info only.
- Evidence per link: URL, status / DNS error, UA.

## BadGEO

- Page with a dead outbound link (expect); page with a bot-blocked and a redirecting outbound link (negative).
