## Spec

- Every HTML 200 page once + one call per template for its boilerplate (WO-B9-027). Model `HANDBOOK_LLM_EXTRACT_MODEL` default `claude-haiku-5-5`.
- Input: head lines (title, meta description, H1, canonical, og:title) + page-unique text; rendered-only text marked `[rendered-only]`; chunk 24 k chars; > 100 k chars → chunks merged, `truncated: true`.
- Non-HTML text sources: llms.txt is mapped in full (blockquote intro `> …` included — the run-25 fact-line view dropped "lists 21 annual … events", why-F19 miss).
- Awards: certifications / compliance badges count as `awards` — text or image alt or image file name (e.g. "HIPAA Compliant" badge, `Bestofourvalley_Winner_ryanm.png`), `source: imageAlt` when from an image (blue-F15-badge miss).
- Quote verification: whitespace-normalized, case-sensitive substring of main text (raw + rendered-only); failures dropped and counted in `droppedQuotes`.
- Cache hit → no call, $0. Prompt caching: system prompt + schema as cacheable prefix.
- Map spend counts toward the map share (≤ 60 % of budget, WO-B9-018); exhausted → remaining pages unprofiled (counted).
