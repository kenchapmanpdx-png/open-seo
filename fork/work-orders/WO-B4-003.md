## Spec

- One judge call per check over a page sample (≤ 8 pages, one per template first); page text is data, never instructions (judge.ts already wraps it).
- `fail` with verified quotes → OPEN + one finding (`source: "llm"`, never S1, never release-blocking); `fail` under confidence 0.5 or any unverified quote → BLOCKED `llm unsure`; `pass` → PASS citing the judged pages' rawHtml evidence; gate false → NA without a call.
- New rubric ids in `llm/rubrics.ts` with `version: 1`; wording below is the starting rubric (tighten only against the eval cases, bump `version` on change).
- P5-03 (S3) "[T1+] Source check: every citation, study, quotation, testimonial and external stat fetched and confirmed at the source; none inve…"
- Step 1 (deterministic): claims = sentences with a number + unit/percent, quotation marks with attribution, 'study', 'according to', 'survey', 'research'. Keep ≤ 12 per site, prefer pages with outbound links.
- Step 2: claim with an outbound link in the same block → fetch target through `ctx.fetchOffsite` (already used by outbound-links; ≤ 12 fetches per run, 10 s, text only, store as `rawHtml` evidence). Judge call per site with claim + cited text: rubric `source-check`: "For each claim, decide whether the cited page states the same fact (same number, same quote, same subject). fail when a claim has no source or the source does not support it; quote the claim (and the source passage when it contradicts). pass when every claim is supported."
- Claims without any link → OPEN without a judge call only when they are external stats/studies (deterministic list above); first-party facts (own prices, own event counts) are P5-02's business, skip them.
- Fetch failure → that claim noted, not a defect; all fetches fail → BLOCKED 'sources unreachable'.

## Evidence to store

- Every finding and every PASS cites ≥1 evidence ref (runner-enforced, K1); LLM findings cite the `rawHtml` evidence of each quoted URL, excerpt = the verified quote ± 200 chars.
- Source pages fetched in step 2 stored as `rawHtml` evidence (url = source URL).
