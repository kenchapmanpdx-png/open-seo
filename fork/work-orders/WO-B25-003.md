## Class

`checks/not-found.ts` treats any live page with the same title as the 404 probe as its twin. A bare-brand title is shared by the 404 template and by any page without a page-specific title, so a correct 404 is flagged.

## Steps

1. **Red test** (public entry point: the not-found check, `checks/not-found.test.ts`): a 404 probe titled "Brand" with 209 words, a live `/cart` titled "Brand" with 120 words, a home titled "Brand | Tagline" with 600 words, `og:site_name` "Brand" → today P3-11. Save to `fork/runs/b25/wo003-red.txt`.
2. **Class fix** in the title branch: when the shared title equals the site's bare brand (`og:site_name` majority, or the home title's brand segment), the match counts only if the probe's word count is within ±10 % of the twin's. Any other title match counts as today. For Ken: say "any title match is a twin" to revert.
