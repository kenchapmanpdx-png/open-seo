  - class ROBOTS (+CRAWL) · automatable partial · severity S3 (default)
- P3-23 rule text (verbatim, §41): "[gate: SP9] Internal search: Disallow OR `noindex,follow` — never both (§11)"
  - class ROBOTS (+CRAWL) · automatable full · severity S3 (default)
- Logic:
  - Gates (SP8/SP3/SP9) are decided at intake; the check runs only for applicable items.
  - P3-21: pagination URLs = links matching `[?&]page=\d+|/page/\d+`. Each must be a visible `<a href>` (it is, if found in links), 200, self-canonical (not canonical to page 1). Out-of-range: not probed by collectors → note 'out-of-range 404 not probed' (no PASS claim on that sub-part; verdict PARTIAL when everything else passes? No: PASS with note — the out-of-range probe is a B3 collector addition; record in note).
  - P3-22: facet URLs = internal links with ≥2 query params or params in (color|size|sort|filter|brand|price). Each facet URL must be Disallowed OR noindex — not both (OPEN on both); indexable facet must be self-canonical.
  - P3-23: search URLs = links/forms to `/search` or `?q=|?s=|?query=`. Must be Disallowed OR `noindex,follow` — never both. Use robots decide for `*` and snapshot robotsMeta when crawled.
- Status mapping: PASS/OPEN per item; NA when no matching URLs found (note 'no pagination/facet/search URLs found')
- Severity: registry `severityDefault` per item; any other severity needs `severityReason` (runner rejects the finding otherwise).
