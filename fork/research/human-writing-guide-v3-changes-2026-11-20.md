## 2. Writing rules

### Do

| ID  | Rule                                                                                                                                                                                                                                                                           | Basis                                   | Grade                                               |
| --- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | --------------------------------------- | --------------------------------------------------- |
| W1  | Load 5 passages of the real author's own writing, same genre as the output. Instruct: match sentence-length spread, vocabulary level and opening habits; do not copy content. Fewer than 5 available → W18.                                                                    | F-01, NA-03, NC-15, NE-04, NE-05        | E1                                                  |
| W2  | Emails and news-style copy: rely on W1. Blog and forum posts: few-shot imitation alone fails (authorship-verification accuracy 16.72–21.25% on blogs, NC-15); edit voice by hand.                                                                                              | NC-15                                   | E1 `STALE?`                                         |
| W4  | State the format explicitly: flowing paragraphs; headings, bullets or bold only where the brief or page template requires them; none in email bodies. No count set by the brief or template → 0 headings and 0 bold inside body prose; ≤3 bullet lists per 10,000 words (E16). | NC-07, NA-08, NE-10, NE-12              | E3; no-brief limits DECIDED (§12 #59)               |
| W12 | Allow a genuine question where the argument turns (AI uses fewer rhetorical questions, NC-04).                                                                                                                                                                                 | NC-04                                   | E3                                                  |
| W13 | Vary sentence length across paragraphs and within each section; variation only registers over several sentences. Readability rule, not a detection fix.                                                                                                                        | NA-06, NC-10, NE-09, NE-10              | E3; DECIDED (§12 #55)                               |
| W14 | Match em-dash use to the author samples; without samples stay ≤1 per 1,000 words. Vary punctuation (commas, colons, parentheses, full stops) rather than banning one mark. Instruct, then post-check: some models keep em dashes under an explicit ban.                        | F-15, NA-07, NA-08, NC-06, NE-10, NE-12 | E3; no-sample limit DECIDED (§12 #57)               |
| W17 | Keep the provider's default sampling settings for business copy, temperature included. Raising temperature lowers open-source detector confidence but raises perplexity, lowers readability and raised fabrication in a vendor sweep.                                          | NA-11, NE-08, NE-07                     | E1 `STALE?`                                         |
| W18 | Never substitute a written style description for samples. Fewer than 5 same-genre samples available → use every one, ≥2 where possible.                                                                                                                                        | NE-05                                   | E3 `STALE?` (open-source verifier, academic essays) |
| W19 | For a named person's voice, generate from ≥1 of their unassisted samples; do not have them post-edit a generic AI draft.                                                                                                                                                       | NE-04, NE-02                            | E3 `STALE?` (open-source style embeddings)          |
| W20 | Prioritise vocabulary variety, em-dash reduction (to the W14 limit) and plain prose over sentence-length or hedge edits.                                                                                                                                                       | NE-10                                   | E3 Practitioner, correlational (⚠ §12 #57, #58)     |
